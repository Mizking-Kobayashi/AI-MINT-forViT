# AI-MINT-forViT
**AI-MINT-forViT** is a project to be able to lip-reading using AI consisted by Vision Transformer(ViT).  

# Description
This project has files such as `.swift` `.mlpackage`.  
So MacOS is only operating-system to run these files.
